# Боты «Спорт и точка» в Telegram и VK

Бот делает в мессенджере то же, что помощник на сайте: ищет встречи, записывает, подаёт заявки, отменяет запись, создаёт встречи с фото, разбирает заявки организатора и присылает уведомления. Спецификация — `docs/product/10-bots.md`.

Бот — обычный клиент сайта. Он ходит в тот же API, что и интерфейс, с личным ключом человека (`stb_…`, заголовок `Authorization: Bearer`). Права, лимиты мест, стоп-лист и тексты ошибок — те же, что на сайте.

## Устройство

```
bots/
  core/            общая логика
    site_client.py   клиент сайта: ошибки сайта → SiteError с готовым текстом, сбой сети → SiteUnavailable
    store.py         SQLite: чаты и привязки, история (12 сообщений), шаги сценариев, кнопки, отправленные уведомления
    vault.py         шифрование ключей людей: DPAPI в Windows, Fernet (BOT_STORE_KEY) на сервере
    render.py        Message / Button / Location — сообщение без привязки к мессенджеру
    engine.py        приём сообщений: команды, кнопки, шаги, свободный текст → помощник; лимит 30 сообщений в минуту
    context.py       контекст сообщения и реестр команд, кнопок и шагов
    flows/           start (вход, меню), search, join, create, requests, organizer, settings, assistant
    notify.py        опрос уведомлений, режимы «все / важные / выкл», тихие часы и утренняя сводка
    texts.py, fmt.py тексты и подписи (даты по поясу города, цена, места, карточка)
    images.py        фото → обложка: до 1280 px, JPEG, data URL до 160 000 символов
  telegram/        адаптер Bot API (long polling) и запуск: python -m bots.telegram
  vk/              адаптер VK Bots Long Poll и запуск: python -m bots.vk
  tests/           сценарии на подменённом сайте (httpx.MockTransport) и мессенджере
```

У кнопки в мессенджер уходит короткий номер (12 символов). Данные кнопки лежат в базе бота. Поэтому лимит Telegram в 64 байта на кнопку не мешает.

## Команды

`/start`, `/help`, `/find <фраза>`, `/today`, `/tomorrow`, `/weekend`, `/near`, `/event <номер>`, `/my`, `/saved`, `/create`, `/requests`, `/myevents`, `/photos`, `/ask <вопрос>`, `/notifications`, `/settings`, `/city`, `/login`, `/logout`, `/cancel`.

Главное меню: «Найти встречу», «На выходные», «Мои записи», «Создать встречу», «Заявки (N)» (только если есть новые заявки), «Помощь». Всё, что не команда, уходит помощнику сайта. Если помощник недоступен или выключен в админке сайта, бот отвечает сам: подбирает встречи, записывает, отменяет запись, создаёт встречу, отвечает справкой по ключевым словам.

## Подключение аккаунта

Пароль в чате не вводится.

- **Ссылка с сайта.** «Настройки → Мессенджеры» выдаёт `t.me/sport_stoloto_bot?start=<код>` или `vk.me/club242415813?ref=<код>`. Бот обменивает код на ключ: `POST /api/bots/link` с заголовком `X-Bot-Secret`.
- **Код с сайта в чат.** Сообщение из шести цифр («123 456» тоже подходит) от неподключённого человека бот считает кодом привязки.
- **Код из бота.** `/login` показывает код (`POST /api/bots/pending`). Бот раз в 3 секунды проверяет, ввели ли его на сайте (`GET /api/bots/pending/<код>`), и сам пишет «Готово».
- У гостя кнопки «Войти через сайт» и «Зарегистрироваться» ведут на `PUBLIC_SITE_URL/bots/link?platform=telegram|vk` (`&signup=1`). После входа сайт возвращает человека в бот ссылкой-привязкой.
- `/logout` отзывает ключ на сайте (`POST /api/bots/unlink`) и забывает его в боте. Если сайт ответил 401 на запрос с ключом, ключ отозван на сайте: бот забывает его и сообщает об этом человеку.

## Уведомления

Раз в `NOTIFY_INTERVAL` секунд бот читает непрочитанные уведомления каждого подключённого человека (`GET /api/notifications`, фильтр `unread`). Каждое уведомление он присылает один раз и прочитанным на сайте его не отмечает. Если новых больше трёх, приходит одна сводка.

Режим — самый строгий из двух:
- настройка бота (`/settings`);
- общий выключатель каналов сайта (`GET /api/delivery/settings`, поле `messengers`, хранится 5 минут; если раздела нет, считается «все»).

Тихие часы — 22:00–08:00 по городу чата. Ночью уведомления копятся, утром приходит одна сводка.

## Запуск

### Telegram — на домашнем ПК (Windows)

1. В @BotFather: `/newbot`, имя «Спорт и точка», ник `sport_stoloto_bot`. Скопировать ключ.
2. Адрес сервера задаётся переменной `SPORT_SERVER` (пользователь@адрес) или параметром `-Server` у обоих скриптов настройки.
   `scripts\set-telegram-bot.ps1`. Скрипт:
   - спрашивает ключ скрытым вводом и, если нужно, прокси;
   - сохраняет их зашифрованными в `%LOCALAPPDATA%\sport-i-tochka`;
   - берёт `BOT_API_SECRET` с сервера по SSH (если его там нет, создаёт);
   - прописывает на сервере `TELEGRAM_BOT_USERNAME`.
3. `scripts\run-telegram-bot.ps1` — запуск. `-Install` — автозапуск при входе в Windows, `-Uninstall` — убрать автозапуск.

База бота — `%LOCALAPPDATA%\sport-i-tochka\telegram-bot.sqlite`, ключи людей в ней зашифрованы DPAPI. Пока ПК выключен, бот молчит. Сообщения Telegram хранит до 24 часов и отдаёт их при запуске. Уведомления за это время придут сводкой.

Без скриптов:

```
set TELEGRAM_BOT_TOKEN=...
set BOT_API_SECRET=...
python -m uv run --project bots python -m bots.telegram
```

### VK — на сервере (Docker)

1. В сообществе:
   - «Управление → Сообщения» — включить;
   - «Сообщения → Настройки для бота» — включить возможности ботов и кнопку «Начать».
2. «Работа с API → Ключи доступа» — создать ключ с правами «сообщения сообщества», «фотографии», «управление сообществом».
3. «Работа с API → Long Poll API» — включить, версия 5.199, события `message_new`, `message_event`, `message_allow`, `message_deny`.
4. `scripts\set-vk-bot-token.ps1` — ключ вводится скрыто и по SSH уходит прямо в `/srv/sport/deploy/.env`. Если на сервере нет `BOT_STORE_KEY` или `BOT_API_SECRET`, скрипт их создаст и предложит перезапустить сервисы.
5. Сервис `vk-bot` в `deploy/docker-compose.yml` стартует вместе с сайтом и ходит в бэкенд внутри сети (`http://backend:8000`). Без `VK_GROUP_TOKEN` он не падает, а спит и пишет в журнал одну строку.

## Переменные окружения

| Переменная | По умолчанию | Что это |
|---|---|---|
| `SITE_URL` | `https://sport.up-point.tech` | куда бот ходит за API (в Docker — `http://backend:8000`) |
| `PUBLIC_SITE_URL` | = `SITE_URL`, если он https | адрес сайта в ссылках для людей |
| `BOT_API_SECRET` | — | общий секрет бота и сайта для привязки и лимита помощника |
| `TELEGRAM_BOT_TOKEN` | — | ключ бота из @BotFather |
| `TELEGRAM_PROXY` | — | `http://…` или `socks5://…`, если api.telegram.org недоступен |
| `VK_GROUP_TOKEN` | — | ключ сообщества VK |
| `VK_GROUP_ID` | `242415813` | номер сообщества |
| `BOT_DB_PATH` | `%LOCALAPPDATA%\sport-i-tochka\<платформа>-bot.sqlite`, в Linux `/data/…` | база бота |
| `BOT_STORE_KEY` | — | ключ Fernet для ключей людей на сервере (44 символа) |
| `NOTIFY_INTERVAL` | `30` | период опроса уведомлений, секунд |

## Безопасность

- В журнал не попадают ключи и личные данные. Адреса Telegram API, `stb_…` и известные секреты заменяются на `***`. Журнал httpx с адресами запросов выключен.
- Ключи людей в базе зашифрованы: DPAPI в Windows, Fernet на сервере. Файл базы в Linux доступен только владельцу (права 600). Если `BOT_STORE_KEY` не задан, ключи лежат как есть, и бот предупреждает об этом в журнале.
- Запросы к помощнику идут с `X-Bot-Secret` и `X-Bot-Chat: <платформа>:<чат>`, чтобы сайт считал лимит по чату, а не по адресу бота.
- Не больше 30 сообщений в минуту от одного чата. Запросы одного чата выполняются по очереди, к помощнику одновременно идут не больше четырёх.
