# Настройка ЮKassa для «Спорт и точка»

Пока ключей нет, сайт работает с тестовой страницей оплаты: всё проходит так же, но деньги не
списываются. Чтобы подключить ЮKassa, сделайте шаги ниже.

## 1. Магазин

1. Зарегистрируйтесь на yookassa.ru и создайте магазин для сайта `https://sport.up-point.tech`.
   Тестовый магазин появляется сразу, без договора: на нём можно проверить всё с тестовыми картами.
2. Для настоящих денег нужен договор (ИП или юрлицо) и модерация сайта. Платформа принимает деньги
   за организаторов и продавцов, поэтому в договоре и оферте сайта нужна агентская схема:
   уточните у менеджера ЮKassa подходящий вариант («Безопасная сделка» или агентская модель с
   «Выплатами»).

## 2. Ключи API

«Интеграция → Ключи API»: скопируйте `shopId` и выпустите секретный ключ (у тестового магазина он
начинается с `test_`). На сервере в `/srv/sport/deploy/.env`:

```
PAYMENTS_PROVIDER=yookassa
YOOKASSA_SHOP_ID=…
YOOKASSA_SECRET_KEY=…
```

Секретный ключ никому не пересылайте в открытом виде и не добавляйте в репозиторий.

## 3. HTTP-уведомления

«Интеграция → HTTP-уведомления» (`yookassa.ru/my/http-notifications-settings`):

- URL: `https://sport.up-point.tech/api/payments/yookassa/webhook`
- События: `payment.waiting_for_capture`, `payment.succeeded`, `payment.canceled`,
  `refund.succeeded` (и `payout.succeeded`, `payout.canceled`, если подключите «Выплаты»).

Сайт всё равно перепроверяет каждый платёж запросом к ЮKassa, так что подделать уведомление нельзя.

## 4. Способы оплаты и холд

- Включите банковские карты и СБП (в настройках способов оплаты или через менеджера).
- Двухстадийные платежи (холд): нужны для складчины и порога сбора, деньги на карте замораживаются
  и списываются только когда встреча точно состоится. Если в настройках нет переключателя, попросите
  менеджера включить двухстадийную оплату для карт. По СБП холда нет: там сайт списывает долю
  сразу и возвращает разницу.

## 5. Чеки (54-ФЗ)

Если подключите «Чеки от ЮKassa»: «Настройки → Чеки», укажите систему налогообложения. На сервере:

```
YOOKASSA_RECEIPTS=true
YOOKASSA_TAX_SYSTEM_CODE=…   # из справочника ЮKassa, например 2 — УСН «Доходы»
YOOKASSA_VAT_CODE=1          # 1 — без НДС
```

По тарифу ЮKassa чек добавляет 1% к комиссии за карты: впишите итоговую ставку в админке сайта
(«Оплата → Ставки»). Как оформлять чеки при агентской схеме, уточните у бухгалтера.

## 6. Выплаты организаторам и продавцам (по желанию)

Подключите «Выплаты» (отдельный шлюз, пополняется со счёта). Ключи — в «Интеграция» шлюза выплат:

```
YOOKASSA_PAYOUT_AGENT_ID=…
YOOKASSA_PAYOUT_SECRET_KEY=…
```

Без них выплаты работают вручную: администратор переводит деньги и нажимает «Переведено».

## 7. Ставки в админке

«Админка → Оплата → Ставки»: впишите ставки из вашего договора (карта, СБП, выплаты). Сайт сам
пересчитает «сбор сервиса» так, чтобы платформа не теряла на комиссиях, а с продажи вещей
получала 5%.

## 8. Перезапуск и проверка

```
cd /srv/sport && docker compose -f deploy/docker-compose.yml up -d
```

В «Админка → Оплата» должно появиться «ЮKassa подключена (тестовый магазин)». Оплатите тестовую
встречу тестовой картой из документации ЮKassa и проверьте, что место подтвердилось, а в «Моих
платежах» появился платёж.
