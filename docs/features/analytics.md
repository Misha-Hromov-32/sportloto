# Спрос и инфраструктура

Экран `/admin/analytics` показывает спрос по районам и направлениям, доступные площадки и разрыв между спросом и предложением. Основания спроса — обезличенные поиски, объявления «Ищу компанию» и отклики. Повторные действия одного человека не увеличивают искусственно число желающих.

Кабинет организации «Спрос рядом» и аналитика администратора используют общий расчёт групп `demandGroupsForAnalytics` из `backend/app/domain/features/demand.py`. Клуб может предложить подходящую встречу группе; уведомления получают заинтересованные люди. Закрытые встречи не входят в публичную аналитику.

Данные демонстрационные, это не статистика реального города. Правила проверяют тесты бэкенда.
