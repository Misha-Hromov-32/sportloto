# Заполнить профиль из ВКонтакте

В форме «Изменить профиль» есть блок «Заполнить из ВКонтакте». Человек вставляет ссылку на свою
страницу и нажимает «Найти страницу». Сайт показывает, что нашёл: фото, текст «О себе», виды спорта
с объяснением («О себе: «бегать»») и уровень. Человек отмечает, что взять, и нажимает «Перенести в
анкету». Текст и виды спорта попадают в поля формы, сохраняет их обычная кнопка «Сохранить профиль».
Фото сохраняется сразу, как при обычной загрузке.

## Как работает

- `POST /api/profile/vk/preview` `{ link }`: ссылка `vk.com/имя`, `vk.com/id123`, `@имя` или `vk.ru/…`
  → `users.get` и `wall.get` API ВКонтакте сервисным ключом приложения (открытые поля страницы и
  10 последних записей на стене, с текстом репостов) → поиск видов спорта из каталога тем же
  разбором, что у поиска фразой. Чем чаще вид упоминается, тем выше: «Есть в 3 записях на стене».
  Уровень по словам «новичок», «любитель», «давно играю». Тексты записей не сохраняются.
- Каждому хотя бы один вид спорта: если спорта на странице нет, модель выбирает подходящий по
  увлечениям и объясняет связь; без модели — по признакам образа жизни (природа → походы, музыка →
  танцы, собака и прогулки → скандинавская ходьба…), иначе вид «для начала». Помечается «совет».
- Фото копируется как data URL: ссылки VK со временем перестают открываться. Предпросмотр ничего
  не сохраняет.
- Если в админке включён режим помощника с моделью, она пишет «О себе» от первого лица и добавляет
  виды спорта только из каталога. Сбой модели — остаётся разбор без неё.
- `GET /api/profile/vk` → `{ enabled }`. Без ключа блок не показывается.
- Не чаще 6 запросов в минуту на человека. Только для вошедших.

## Включить

1. dev.vk.com → «Мои приложения» → «Создать» (веб-приложение) → «Ключи доступа» → сервисный ключ.
2. На сервере в `deploy/.env`: `VK_SERVICE_TOKEN=…`, затем `docker compose -f deploy/docker-compose.yml up -d`.

Код: `backend/app/integrations/vk.py`, `backend/app/api/routes/profile_import.py`,
`frontend/src/pages/profile/parts/VkImport.tsx`.
