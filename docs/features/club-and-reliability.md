# Управление клубом и надёжность

Организатор скачивает список участников события таблицей (CSV): «Управление событием» → «Скачать список участников». Ячейки экранируются, контактов в таблице нет.

После встречи участники отвечают «Встреча состоялась?». Карточка события, страница организации и профиль показывают проверяемые факты о проведённых и отменённых встречах и ответы участников («Подтвердили участники: 5 из 7 встреч»). Это факты прототипа, не вычисленный рейтинг человека.

В кабинете клуба есть «Управляющие клуба»: владелец добавляет до пяти зарегистрированных людей по почте и отзывает доступ с подтверждением. Управляющий может выйти сам; владельца удалить нельзя. Управляющему доступен кабинет и управление встречами, редактирование сведений организации остаётся у владельца. В обсуждении организатор закрепляет своё видимое сообщение кнопкой «Закрепить» и снимает закрепление кнопкой «Открепить». Закреплённый текст отображается над обсуждением с переходом к исходному сообщению; одновременно закреплено одно сообщение.

## Как проверить

1. Дмитрий (`dmitry@vmeste.demo`) → «Управление событием» любой своей встречи с участниками → «Скачать список участников».
2. Анна (`anna@vmeste.demo`) → `/me`: вопрос «Встреча состоялась?» о прошедшей йоге; ответ одним нажатием.
3. Карточка встречи клуба «Ладья» → блок организатора: строка «Подтвердили участники…».

Правила проверяют тесты бэкенда.
