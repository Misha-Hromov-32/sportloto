# Импорт встреч из сообществ

Администратор открывает `/admin/imports`, загружает JSON или текст либо использует демонстрационный файл `frontend/public/demo/community-posts.json`. Повторная загрузка не создаёт дубли. Помощник выделяет время, место и направление; администратор проверяет и исправляет черновик перед публикацией.

Пост без обязательных условий опубликовать нельзя. Посты без встречи можно отклонить. Телефоны и персональные идентификаторы автора не переносятся в публичную карточку. Опубликованное событие содержит ссылку на источник; представитель сообщества может подать заявку, чтобы забрать управление после допуска.

Это импорт из файла. Автоматического подключения к социальным сетям нет. Правила проверяют тесты бэкенда.
