# Ссылка близкому и карточки без сети

Подтверждённый участник может создать ссылку близкому из карточки события и отозвать её. Страница `/share/:token` открывается без входа и показывает ограниченную памятку: название, время, адрес, как найти, контакт организатора и имя участника. Ссылка работает до конца встречи; после отзыва, отмены записи, отмены или снятия встречи страница скрывает подробности и объясняет почему.

Ближайшие записи можно сохранить на устройстве через раздел в `/me`. Уже сохранённая карточка доступна без сети и отмечает время сохранения. Это локальная памятка, а не полная офлайн-версия приложения: новые записи, заявки и обсуждение требуют работающего приложения.

## Как проверить

1. Анна (`anna@vmeste.demo`) → `/events/e-run-tatyshev` → «Записаться» → блок «Поделиться с близким» → «Поделиться с близким» → «Скопировать ссылку».
2. Откройте ссылку в окне инкогнито или другом браузере: памятка «Подробности встречи, на которую идёт Анна» без входа.
3. Под Анной «Отозвать ссылку» → страница по ссылке показывает «Ссылку отозвали».

Правила проверяют тесты бэкенда.
