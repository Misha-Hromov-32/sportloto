# Подключить ассистента

На `/settings/assistant` пользователь выпускает личный токен, выбирает права чтения, участия и подготовки черновиков, срок действия; может отозвать его и посмотреть журнал вызовов. Секрет показывается при выпуске, сохраняется его хеш. Есть встроенная консоль проверки JSON-RPC.

Каталог поддерживает `tools/list`, вызовы — `tools/call`. Используются те же доменные проверки прав, что в интерфейсе. Изменяющим действиям требуется подтверждение; черновик события публикует человек. Предусмотрены срок действия, отзыв и ограничение частоты вызовов.

С сервером внешний MCP-клиент подключается к `POST /mcp` с этим токеном в заголовке `Authorization: Bearer …`. Встроенная консоль показывает те же вызовы. Подробности — `docs/architecture/mcp.md`.
