# Чат-бот помощник

> 03.11.2026: общий выключатель управляет моделью. Формы, разбор поиска, предмодерация на правилах и MCP имеют независимые флаги и не требуют ключа модели. Формы/поиск/предмодерация доступны по умолчанию; MCP включается отдельно. Встроенный режим допускается без ключей. Чат выполняет действия только после подтверждения. Справка сообщает, что платежи через сайт отключены.

Чат в шторке на любой странице и на `/assistant`. Подсказывает, как устроен сайт (куда перейти, что
нажать), подбирает встречи системой рекомендаций и делает дела за человека после подтверждения.

## Что умеет

- **Отвечает, как что сделать.** База знаний `frontend/src/pages/chat/knowledge.ts`: 60 тем и карта
  из 37 страниц с точными названиями кнопок. Ответ — короткое объяснение, шаги и ссылки.
- **Подбирает встречи.** Через `/assistant/match`, ту же систему, что и «Для вас»: карточки с
  причинами («Ваше направление», «Рядом: 900 м») и кнопкой «Записаться».
- **Делает за человека:** создаёт встречу (по шагам спрашивает вид спорта, время и место),
  записывает на встречу и отменяет запись, публикует объявление «Ищу компанию», сохраняет встречу
  в избранное, добавляет интересы и район в профиль, открывает нужную страницу. Перед каждым
  действием показывает карточку с данными и кнопками «Подтвердить», «Отмена» и ссылкой на обычную
  форму. Действие выполняется обычными запросами сайта с правами человека.

## ИИ на сайте (админка → «ИИ на сайте», `/admin/assistant`)

По умолчанию модель выключена: чат отвечает по правилам и базе знаний (`pages/chat/engine.ts`).
Формы, поиск и предмодерация на правилах включаются независимо от модели; MCP имеет отдельный флаг.
Для внешней или локальной модели нужны адрес и модель, ключ API или подключённый мост.
Встроенный режим работает без ключей. Настройки модели при выключении сохраняются.

Ниже общего выключателя у каждой функции свой флажок. Сервер отдаёт итог в `features` ответа
`GET /api/assistant/config`:

| Функция | Включена | Выключена |
| --- | --- | --- |
| `chat` | чат отвечает моделью | чат отвечает без модели |
| `forms` | заполнение встречи, организации и объявления по фразе | обычная форма |
| `search` | разбор фразы и панель подбора в ленте и на главной | поиск по словам и фильтры |
| `premoderation` | пометки `aiFlag` на текстах для администратора | пометок нет |
| `covers` | кнопка рисования обложки (только через мост) | только своё фото |
| `profile` | модель дополняет анкету из ВКонтакте | анкета без модели |
| `digest` | модель пишет вступление к письму подборки | обычное вступление |
| `bots` | свободный текст и встреча одной фразой в ботах | кнопки, поиск по словам, создание по шагам |
| `mcp` | `/mcp`, `/api/mcp/*`, раздел настроек и кнопка на главной | адреса отвечают 404, раздела и кнопки нет |

`forms`, `search` и `premoderation` работают на правилах (`app/domain/assistant.py`): выключатель
управляет ими, но модель они не вызывают.

| Чем работать | Как отвечает |
| --- | --- |
| Локальная модель | OpenAI-совместимый сервер в своей сети (Ollama, LM Studio). |
| Мост на компьютере | Программа `bridge/` на ПК по WebSocket, отвечает через Codex CLI. |
| Внешний API | OpenAI-совместимый API по ключу, GigaChat или YandexGPT. |

Модель получает правила, базу знаний (`backend/app/assistant/knowledge.md`, собирается командой
`node scripts/run-ts.mjs scripts/export-assistant-knowledge.ts` в `frontend`), профиль человека, его
записи, подборку «Для вас» и ближайшие встречи. Отвечает JSON по схеме: текст, ссылки, фраза для
подбора, предложенное действие, уточняющий вопрос. Сервер проверяет ответ: ссылки только внутри
сайта, параметры действий по списку.

Если модель не ответила за заданное время (5–120 секунд), ИИ выключен или мост не подключён, чат
отвечает без модели. Сценарии S1–S6 от модели не зависят.

## Где код

- Сервер: `backend/app/assistant/` (настройки, мост, подсказка, модели),
  `backend/app/api/routes/assistant.py`, тесты `backend/tests/test_assistant_chat.py` и
  `backend/tests/test_ai_switches.py`.
- Чат: `frontend/src/pages/chat/` (`engine.ts` — ответы без модели, `actions.ts` — действия,
  `remote.ts` — ответ моделью), правила проверяют тесты бэкенда и проверки интерфейса.
- Админка: `frontend/src/pages/admin/assistant/`.
- Мост: `bridge/` (см. `bridge/README.md`).
