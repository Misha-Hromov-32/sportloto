# Жалобы и приостановка допуска

Пользователь может пожаловаться на событие или сообщение, выбрать основание и описать проблему. Повторная жалоба не создаёт дубль. Администратор рассматривает очередь, отклоняет жалобу либо применяет действие с причиной и пунктом правил. Автор жалобы видит результат.

В карточке организации администратор может приостановить её допуск с объяснением и затем восстановить. Представитель видит причину и ограничение публикации. Действия записываются в журнал. Подсказка предмодерации не принимает решение за администратора.

Правила проверяют тесты бэкенда, включая базовое снятие события (S6).
