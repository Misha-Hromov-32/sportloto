# Демонстрация: проверка S1–S6 и показ на 5 минут

Этот сценарий предназначен для отдельного локального стенда с тестовой базой и включёнными
демо-функциями в окружении `APP_ENV=test`. На рабочем сайте демовход и сброс данных закрыты,
а вход администратора требует пароль. Обычный production-запуск Compose демоданные не загружает.

Один план для экспертов, для заметок к слайду 10 и для живого показа. Сначала шесть базовых сценариев (обе ветки
S2 и S4), затем три флагманские доп. функции со слайда 12. Все люди, клубы и встречи ниже — из демо-данных
Красноярска, они загружаются при первом запуске.

## Подготовка

1. Откройте локальный тестовый стенд, город — Красноярск.
2. Войдите на странице `/login` в блоке «Проверяете прототип? Демо-аккаунты всех ролей». Если у администратора
   в блоке нет кнопки, войдите через форму: `maria@vmeste.demo`, пароль пустой. У каждой вкладки свой вход,
   поэтому для живых обновлений откройте несколько вкладок (одинаковый адрес и порт).

| Вкладка | Аккаунт | Роль в показе |
|---|---|---|
| 1 | Анна Соколова | участница-новичок: S3, S4, S5, флагманы |
| 2 | Дмитрий Орлов | частный организатор: S1, S4, S5 |
| 3 | Мария Белова | администратор: S2, S6 |
| 4 | Сергей Лаптев | беговой клуб «Енисей», заявка на проверке: S2, ветка допуска |
| 5 | Наталья Орехова | клуб северной ходьбы «Шаг», заявка на проверке: S2, ветка отказа |

3. Проверьте исходное состояние: «Енисей» и «Шаг» на проверке; Анна не записана на «Утреннюю пробежку по острову
   Татышев», «Волейбол в зале: смешанные команды» и «Стритбол 3×3»; «Блиц-вечер и разбор партий» опубликован.
   На рабочем сервере это состояние могли изменить другие проверяющие — тогда берите соседние встречи с тем же
   режимом записи. На своём стенде верните исходные данные (демо-режим, `DEMO_LOGIN_ENABLED=true`):

   ```bash
   TOKEN=$(curl -s -X POST -H 'Content-Type: application/json' -d '{"userId":"u-maria"}' \
     http://localhost:8080/api/auth/demo-login | jq -r .token)
   curl -X POST -H "Authorization: Bearer $TOKEN" http://localhost:8080/api/demo/reset
   ```

Подробные шаги — ниже, в том же порядке.

## S1. Пользователь создаёт встречу

1. Дмитрий: «Создать встречу». В поле «Направление» введите «Петанк». Его нет в каталоге — нажмите
   «Добавить «Петанк» как новое направление» (если сервис предложит похожее, выберите создание нового).
2. Название, дата, время и место; на шаге «Кто и как» выберите запись «По заявке»; условия, например «шары дадим,
   форма любая». На шаге «Проверка» нажмите «Опубликовать».
3. Анна: «Найти занятие» → поиск «петанк» → карточка. Видны направление, организатор, условия и режим записи.
   Код не менялся: новое направление сразу ищется, администратор может объединить похожие в `/admin/sports`.

Ветка с известным направлением проходит так же: выберите, например, «Бег» из подсказок.

## S3. Свободная запись

1. Анна: «Утренняя пробежка по острову Татышев» → «Записаться». Статус «Вы идёте», мест стало на одно меньше.
2. Дмитрий: эта встреча → «Управлять встречей»: Анна в списке участников, обновление пришло без перезагрузки.

## S4. Запись по заявке — обе ветки

1. Принятие. Анна: «Волейбол в зале: смешанные команды» → «Отправить заявку» с комментарием «Играла в школе».
   Статус — «на рассмотрении», Анна ещё не участница.
2. Дмитрий: волейбол → «Управлять встречей» → вкладка «Заявки» → у Анны «Принять». У Анны статус сменился на «участник»
   без перезагрузки, у Дмитрия она в составе.
3. Отказ. Анна: «Стритбол 3×3 на открытой площадке» → «Отправить заявку». Дмитрий: «Заявки» → у Анны
   «Отклонить», причина «Нужен опыт игры, попробуйте волейбол для начинающих». Анна видит отказ и причину в
   карточке и в уведомлении; Дмитрий видит её среди отклонённых.

Готовые заявки без подготовки: на стритболе ждут решения Максим Егоров и Никита Белов; в клубе «Ладья» (Ольга
Ветрова) на «Воскресном турнире по рапиду» ждёт заявка Петра — её можно отклонить и увидеть результат под Петром.

## S5. Уточнение условий

1. Анна: карточка пробежки → «Обсуждение» → «Можно прийти, если бегаю только 3 км?».
2. Дмитрий отвечает в той же ветке: «Да, чередуем бег с шагом». У ответа пометка «Организатор», у Анны ответ
   появляется сразу. Сообщения видны всем, кто открывает карточку.

## S2. Допуск организации — обе ветки

1. Сергей: в кабинете клуба «Енисей» статус «на проверке», публиковать от имени клуба пока нельзя.
2. Мария: «Организации» → «Беговой клуб «Енисей»» → «Допустить».
3. Сергей: статус «допущена». «Создать встречу» → «От чьего имени публикуем» → клуб «Енисей» → «Опубликовать».
   Встреча сразу в ленте, повторного согласования нет. Анна открывает страницу клуба и эту встречу.
4. Отказ. Мария: «Клуб северной ходьбы «Шаг»» → «Отклонить заявку» с причиной, например «Добавьте контакты
   и расписание». Наталья видит причину, исправляет заявку и отправляет снова; до допуска публичной страницы нет.

Готовый пример отказа: Игорь Ким, «Пиксель» — причина уже видна в его кабинете.

## S6. Снятие с публикации

1. Мария: карточка «Блиц-вечер и разбор партий» (клуб «Ладья») → «Снять с публикации» → пункт правил и
   комментарий.
2. Анна: встречи нет в поиске, по прямой ссылке записаться нельзя. Участники (например, Пётр) и Ольга получили
   уведомление с причиной. Мария может вернуть встречу после исправления — записи восстановятся.

## Флагманские доп. функции (слайд 12)

1. **«Я впервые — меня встретят».** Анна: «Волейбол для начинающих на Взлётке». В карточке блок «Впервые? Вас
   встретят» — новичков встречает Дмитрий. Отметьте «Я здесь впервые» и запишитесь: в «Что дальше» появится
   памятка с приметами («у входа со двора в 10:50, в красной куртке и с мячом»). Дмитрий в управлении видит
   «Придут впервые».
2. **«Соберёмся, если придут N».** «Хоккей на крытом льду: ночная игра» — полоса и фраза «до сбора нужно ещё 8».
   «Футбол 7×7 на искусственном поле» — мест нет, кнопка «Встать в лист ожидания». Когда место освобождается,
   его 3 часа держат за следующим в очереди: на свежих демо-данных у Анны уже есть такое предложение на
   «Бадминтон пара на пару» — кнопка «Иду» в карточке.
3. **«Ищу компанию» → встреча.** Анна: «Ищу компанию» → «Ваши объявления» → объявление про волейбол с двумя
   откликами «Я тоже» → «Собрать встречу». Форма заполнена из объявления; после публикации откликнувшиеся сразу
   получают место и уведомление.

## Если что-то пошло не так

- Нет сети: показывайте слайды 12–13 — там кадры этих функций с рабочего сервера.
- Помощник недоступен: ручной поиск, создание и запись работают без него (отказ можно включить в демо-режиме
  запросом `POST /api/demo/assistant-failure`).
- Карта грузится из интернета; в карточке всегда есть текстовый адрес.
- Оплату на показе не проводим: у демо-встреч оплата на сайте выключена.
