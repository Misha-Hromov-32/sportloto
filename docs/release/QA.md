# Проверка комплекта

Приложение — интерфейс и сервер в Docker Compose. Всё запускается в Docker. Ниже — что проверяется и чем; результаты конкретных прогонов в документ не вносятся, их даёт запуск.

## Автоматические проверки

- **Бэкенд, pytest.** Самое важное: шесть базовых сценариев, выключатели ИИ, оплата, вход и сессии, удаление аккаунта, ошибки, слой хранения, демо-данные, миграции.
- **Оценка помощника.** 65 фраз из `backend/tests/assistant_eval_cases.json` прогоняет `backend/tests/test_assistant_eval.py`, он входит в pytest.
- **Формат и стиль бэкенда.** `ruff format --check` и `ruff check`.
- **Фронтенд, `npm run check`.** ESLint, проверки интерфейса, TypeScript и production-сборка.
- **Сценарии запросов, `scripts/scenarios`.** Прогон сценариев против запущенного сервера: сравниваются коды ответов с прошлым прогоном, любой 5xx — ошибка. Запуск и формат — `scripts/scenarios/README.md`.
- **Браузер, `scripts/e2e`.** Chromium в Docker против стека с nginx: вход по почте демо-аккаунта, лента с сервера, запись из карточки, вход организатора на `/demo`, уведомления, живые обновления без перезагрузки. Проверяются ошибки консоли и ответы 5xx.

## Ручная проверка

Выборочно просматриваются ключевые сценарии S1–S6 и экраны:

- создание и публикация встречи, запись, заявка и её решение, вопросы и ответы, допуск организации, снятие события с причиной;
- семейная запись с детьми, запись компанией, лист ожидания;
- чат-помощник (поверх страниц и на полной странице `/assistant`), тема «Графит», крупный текст, простой режим;
- мобильная ширина 375 px: навигация, формы, кнопка чата над нижней панелью.

Снимки — `docs/release/screens/`. Это визуальная проверка ключевых экранов, а не аудит доступности по WCAG.

## Презентация

Девять редактируемых слайдов с заметками выступающего. Финальный PPTX проверен по структуре, геометрии и шрифтам, повторно импортирован и отрендерен. Проверка в установленном PowerPoint не выполнялась.

## Границы

Демонстрационный вход не проверяет пароль и отключается переменной `DEMO_LOGIN_ENABLED=false`. Помощник по умолчанию использует правила; модель, мост и внешний API подключаются настройками. Импорт — из файла. Камеры и трансляции — развитие. Размещение на внешнем сервере не выполнялось; публикацию владелец делает самостоятельно (`DEPLOY.md`).
