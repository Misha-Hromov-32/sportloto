# UX: информационная архитектура и экраны (v1)

Источник для интерфейса и разработки. Опирается на `06-domain.md` (сущности, статусы, права),
`03-scenarios.md` (112 сценариев, чек-лист состояний) и концепцию в `00-plan.md`.

Продукт: **«Вместе»**. Город демо-данных: Красноярск.

## 1. Принципы UX
1. **Один главный шаг на экран.** Главная кнопка экрана одна, крупная и называет действие («Записаться», «Отправить заявку», «Опубликовать»).
2. **Статус словами.** Состояние записи, заявки и публикации всегда показано текстом с иконкой. Цвет только подкрепляет.
3. **Ничего не теряется.** Черновики сохраняются, переключение режимов не стирает ввод, после входа пользователь возвращается туда, где был.
4. **Новичку — меньше.** «Простой режим» показывает три большие кнопки и крупный текст. Остальное открывается по мере использования.
5. **Помощник — ускоритель, а не обязательный путь.** Рядом с каждой функцией помощника есть ручной путь.
6. **Живые обновления.** Статусы меняются без перезагрузки у всех сторон (по SSE с сервера).

## 3. Навигация
**Мобильная** (до 768px): нижняя панель из пяти пунктов: **Найти** · **Компания** · **＋ Создать** (центр, акцент) · **Мои** · **Профиль**. Для левши (настройка) главная кнопка и плавающие действия зеркалятся.
**Десктоп:** шапка: логотип · Найти · Ищу компанию · Мои занятия · [Создать] · уведомления · аватар-меню (профиль, настройки, мои организации, сменить аккаунт, выйти).
**Админ:** отдельный лэйаут `/admin` с боковым меню: Сводка · Организации · Мероприятия · Обсуждения · Направления · Журнал. Переход «На сайт».
**Гость:** шапка с «Войти» и «Присоединиться». Смотреть ленту и карточки можно, действие («Записаться», «Спросить») ведёт на вход и возвращает обратно.

## 5. Ключевые потоки (кратко)
**S1. Создать событие (пользователь).** Создать → «Заполню сам» → направление: поиск по каталогу; если нет → «Добавить «Городки» как новое направление» (на похожее: «Возможно, вы имели в виду…») → дата/время/место → режим записи (две большие карточки-варианта с объяснением) → лимит и порог → «Первый шаг» → предпросмотр → «Опубликовать» → экран успеха: «Готово, событие в поиске» + «Поделиться» + «Открыть».
**S1 с помощником.** «Создать с помощником» → поле «Расскажите о встрече одной-двумя фразами» (+ микрофон) → «Помощник думает…» → «Вот что я понял — проверьте» (поля с пометкой) → уточнение «Во сколько? 10:00 / 18:00 / другое» → предпросмотр → «Опубликовать». Сбой → «Помощник сейчас недоступен…» → ручная форма с текстом в описании.
**S2. Организация.** Профиль → «Зарегистрировать организацию» → форма → «Отправить на проверку» → кабинет «На рассмотрении, обычно до 1 дня». Админ: Сводка → заявка → «Допустить» / «Отклонить: причина». Организация: уведомление + статус в кабинете. После допуска: «Создать событие» с автором «Ладья» → публикуется сразу → страница организации показывает событие.
**S3. Свободная запись.** Карточка → «Записаться» → (подтверждение одной строкой: «Вы идёте на … в субботу в 10:00») → статус «Вы участник» + блок «Что дальше»: как найти, что взять, «Добавить в календарь», контакты организатора. У организатора участник появляется сразу (живое обновление).
**S4. По заявке.** Карточка → «Отправить заявку» → (необязательное сообщение организатору) → статус «Заявка на рассмотрении — вы ещё не участник». Организатор: «Управление» → «Заявки (2)» → «Принять» / «Отклонить» (+ причина по желанию). Участник: статус меняется без перезагрузки + уведомление.
**S5. Вопрос.** Карточка → «Обсуждение» → «Задать вопрос» → сообщение. Организатор: ответ с меткой «Организатор» (у организации — её логотип и название), можно «Ответить на сообщение». Гость: «Войдите, чтобы спросить».
**S6. Снятие.** Админ → мероприятие → «Снять с публикации» → причина → подтверждение. Событие пропадает из ленты, по прямой ссылке — баннер «Снято с публикации модератором: причина», записи нет. Записавшиеся: статус «Мероприятие снято с публикации» + уведомление. Организатор: причина и «Исправить и попросить вернуть».

## 6. Обязательные состояния каждого экрана
Загрузка (скелетоны по форме контента) · пусто (объяснение + следующий шаг) · ошибка (что случилось + что сделать) · нет прав (почему + как получить) · снято / отменено / прошло · гость. Чек-лист — `03-scenarios.md`, финальный раздел.

## 6а. Дополнения после разбора штурма (`04-ideas.md`) — входят в прототип
1. **Прогрессивный интерфейс.** Новичку по умолчанию показываем главное (три крупных действия: «Найти занятие», «Ищу компанию», «Создать встречу»). Остальное раскрывается по ролям и действиям (например, «Управление» появляется, когда есть свои события). Действия S1–S6 не прячутся никогда.
2. **Двусторонний «Ищу компанию».** В профиле и объявлении — статус «Готов присоединиться» или «Хочу организовать». У объявления есть «Я тоже» и «Позвать»: приглашение на конкретное своё событие, приходит уведомлением.
3. **Деньги без реальных платежей.** В карточке: «Бесплатно» / «Фиксированная цена» / «Скидываемся: аренда 2 400 ₽ на всех» с пересчётом «≈ 200 ₽ с человека при 12 участниках, не больше 300 ₽ при пороге 8». Правило отмены выбирает организатор («Можно отменить бесплатно до 18:00 накануне»), участник видит его до записи. Отмена события организатором означает полный возврат, текст объясняет это. Оплата — на месте или по договорённости, в прототипе без платёжной системы.
4. **Каталог-дерево.** Категории: Игровые, Циклические, Единоборства, Интеллектуальные, Фиджитал, Фитнес и здоровье, Зимние, Для старшего поколения… Популярные направления наверху, поиск по всему справочнику. У категории могут быть свои доп. поля (например, «Контроль времени» у шахмат, «Покрытие» у тенниса). Поля хранятся как данные, новое направление и новое поле добавляются без кода.
5. **«Рядом со мной» и карта.** Точка отсчёта (район или «моё место»), радиус 1/3/5/10 км, переключатель «Список / Карта» в ленте (Leaflet + OpenStreetMap). Расстояние в карточке.
6. **Лёгкие:** фильтр цены «Бесплатно / до N ₽»; печатная афиша А4 с QR-кодом (`/events/:id/poster`) для двора и подъезда; повтор встречи «каждую неделю до даты»; тип организации «Тренер / авторская школа»; метки «Организация проверена» / «Встреча частного лица» и факты «провёл 14 встреч, отменил 1»; история прошедших занятий и спокойная коллекция «Попробовал: 5 направлений»; лендинг с живыми ближайшими событиями; страница **«Правила платформы»** (`/rules`), причина снятия ссылается на пункт правил.
7. **Не делаем:** тематические чаты, турниры и сетки, судейство, онлайн-занятия, рейтинги людей, посты и видео участников.

## 7. Помощник в интерфейсе
- Пометка: значок «Заполнил помощник» у поля и подсказка «почему так».
- Состояния: «Помощник думает…» (до 1,5 с), «Вот что я понял — проверьте», уточняющий вопрос с кнопками, ошибка с возвратом к форме.
- Ответы помощника на правилах опираются на ключевые слова (футбол, теннис, шахматы, бег, йога, «завтра», «в субботу», «утром», «новичок», «бесплатно»), чтобы демо-фразы давали правдоподобный результат.
- Поиск фразой: результат — чипы фильтров, каждый можно снять.
- Подбор: подпись «Вам подходит: тот же район, уровень «начинающий», по вечерам».
- Предмодерация: у сообщения или заявки в админке — пометка «Похоже на спам: 3 ссылки за минуту» и кнопки решения.
