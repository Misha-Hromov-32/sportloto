# Боты «Спорт и точка» в Telegram и VK

Статус: принято (20.10.2026, решение владельца в режиме «решаю сам», D-17).

Бот делает в мессенджере всё, что умеет помощник на сайте, и работает с сайтом от имени человека:
- ищет встречи, записывает, подаёт заявки, отменяет запись;
- создаёт встречи, в том числе с фото;
- разбирает заявки, если человек организатор;
- присылает уведомления.

Telegram-бот запускается на домашнем компьютере владельца, VK-бот работает на сервере сайта.

## 1. Как устроено

```
Telegram (long polling) ─┐                     ┌─ /api/assistant/chat  (тот же помощник, что на сайте)
                          ├─ bots/core ─ HTTPS ─┤─ /api/events, /participations, /notifications …
VK (Bots Long Poll) ──────┘   (общая логика)    └─ /api/bots/*  (привязка аккаунта)
```

- **Один код на два мессенджера.** В `bots/core` лежат команды, сценарии, отрисовка карточек, хранилище состояния (SQLite) и опрос уведомлений. `bots/telegram` и `bots/vk` — тонкие адаптеры: принять сообщение, отправить текст, кнопки и фото.
- **Бот — обычный клиент сайта.** Он ходит в тот же API, что и интерфейс, с личным ключом человека. Поэтому права, проверки, лимиты мест, стоп-лист и тексты ошибок те же, что на сайте. Правила дважды не пишутся.
- **Без новых тяжёлых библиотек.** API Telegram и VK вызываются через `httpx`, он уже есть в проекте. Telegram-бот на домашнем ПК запускается одной командой через `uv`.

## 2. Вход: привязка аккаунта

Пароль в мессенджере не вводится никогда.

### Ссылка с сайта (основной путь)
1. На сайте: «Настройки → Мессенджеры → Подключить Telegram» (или VK). Сайт выдаёт одноразовую ссылку на 10 минут:
   - Telegram: `t.me/<бот>?start=<код>`;
   - VK: `vk.me/club242415813?ref=<код>`.
2. Человек нажимает ссылку, мессенджер открывает бота, бот получает код.
3. Бот сообщает код сайту (`POST /api/bots/link`, запрос подписан секретом бота). Сайт возвращает личный ключ бота для этого человека.
4. Бот пишет: «Готово, Анна. Аккаунт подключён» и показывает главное меню.

### Код из бота (если ссылка не открылась)
1. В боте: «Подключить аккаунт». Бот показывает шестизначный код.
2. На сайте в «Настройки → Мессенджеры» человек вводит код и нажимает «Подключить».

### Ключ бота
- Формат `stb_…`. Сайт хранит только хеш, ключ живёт 365 дней.
- Принимается везде, где принимается вход (`Authorization: Bearer`).
- В «Настройки → Мессенджеры» видно: «Telegram, @anna_run, подключён 20 октября», кнопка «Отключить». Ключ отзывается сразу.
- В боте `/logout` отключает аккаунт с обеих сторон.

### Без аккаунта
Можно искать встречи, смотреть карточки и спрашивать помощника. На «Записаться», «Мои записи» и «Создать» бот отвечает: «Чтобы записаться, подключите аккаунт: [Войти через сайт] [Зарегистрироваться]». Обе кнопки ведут на сайт со ссылкой-привязкой: после входа бот подключится сам.

## 3. Команды

Команды есть и в меню мессенджера, и кнопками. Писать можно и обычными словами: всё, что не команда, уходит помощнику.

| Команда | Что делает |
|---|---|
| `/start` | Приветствие, главное меню. `/start <код>` — привязка |
| `/help` | Все команды с примерами |
| `/find <фраза>` | Подбор по фразе: «волейбол в субботу вечером» |
| `/today`, `/tomorrow`, `/weekend` | Встречи на сегодня, завтра, выходные |
| `/near` | Встречи рядом. Бот просит геопозицию кнопкой «Отправить местоположение» (только Telegram) или район |
| `/event <номер>` | Карточка встречи |
| `/my` | Мои записи и заявки: статусы, место в очереди, кнопки «Отменить», «Вопрос организатору», «Как добраться» |
| `/saved` | Избранное |
| `/create` | Создать встречу (сценарий в п. 5) |
| `/requests` | Заявки на мои встречи по одной: «Принять», «Отклонить», «Позже» |
| `/myevents` | Встречи, которые я провожу: участники, заявки, «Отменить встречу», «Добавить фото» |
| `/photos` | Фото «Как это было» к прошедшей встрече (организатор) |
| `/ask <вопрос>` | Вопрос по правилам и работе сайта |
| `/notifications` | Непрочитанные уведомления |
| `/settings` | Город, уведомления (все / только важные / выкл.), тихие часы |
| `/city` | Сменить город: Красноярск, Москва, Брянск |
| `/login`, `/logout` | Подключить и отключить аккаунт |
| `/cancel` | Выйти из текущего шага |

**Главное меню** (постоянная клавиатура Telegram / кнопки VK):
- «Найти встречу», «На выходные»;
- «Мои записи», «Создать встречу»;
- «Заявки (3)» — только у организатора с новыми заявками;
- «Помощь».

## 4. Карточка встречи в чате

```
[фото обложки]
🏐 Волейбол в зале: смешанные команды
Чт, 22 октября · 19:30 · через 2 дня
📍 Спортзал школы № 10, ул. Лады Кецховели, 22
👥 7 из 12 · свободно 5 · по заявке
💳 ≈300 ₽ · для любителей
Организатор: Дмитрий Орлов
Почему вам подходит: любите волейбол, рядом с домом

[Записаться] [♥] [Подробнее] [Открыть на сайте]
```

- В подборе приходят три карточки и кнопка «Ещё».
- «Подробнее» присылает описание, «Первый шаг» (что взять, как найти) и точку на карте (Telegram `sendVenue`, VK `geo`).
- **«Записаться»:**
  - свободная запись — подтверждение «Записать вас на … ?» [Да] [Нет];
  - по заявке — бот просит сообщение организатору, его можно пропустить кнопкой;
  - пересечение по времени — «В это время у вас … [Всё равно записаться] [Отмена]»;
  - нет мест — предложение встать в лист ожидания.
- Ошибки сайта приходят тем же понятным текстом, что на сайте: стоп-лист, состав, приглашение.

## 5. Создать встречу

Два пути, как на сайте.
- **Одной фразой:** «футбол в субботу в 11 на стадионе Енисей, 10 человек, бесплатно». Бот разбирает фразу тем же помощником (`/api/assistant/draft`) и показывает черновик. Потом спрашивает только недостающее: место, время, лимит.
- **По шагам:** вид спорта (кнопки популярных + «Другой») → дата (кнопки «Сегодня / Завтра / Сб / Вс / Другая») → время → место (текст или геопозиция) → лимит → цена → запись свободная или по заявке → «Добавьте фото обложки или нажмите «Пропустить»».

Дальше:
- **Фото:** бот берёт присланную картинку, уменьшает её до размеров сайта (до 1280 px, WebP или JPEG, не больше 160 000 символов в data URL) и ставит обложкой.
- **Предпросмотр:** карточка, как её увидят участники, и кнопки [Опубликовать] [Изменить …] [Отмена].
- **Публикация:** `POST /api/events` с ключом идемпотентности, чтобы повторное нажатие не создало две встречи. Ответ: «Опубликовано» и ссылка на сайт.

## 6. Заявки (организатор)

`/requests` — та же логика, что режим «По одной» на сайте, по одной карточке:

```
Анна Соколова, 34 года · любитель
Встреч на платформе: 7
«Играю 3 года, могу взять свой мяч»
Заявка 2 часа назад · Волейбол в зале, Чт 19:30 · свободно 5 из 12

[Принять] [Отклонить] [Позже]
```

- **«Отклонить»:** кнопки причин (те же шаблоны, что на сайте), «Своими словами», «Без причины».
- **«Вернуть»:** после решения 5 секунд можно отменить. Сообщение «Анна принята · [Вернуть]» меняется на «Анна принята» по истечении срока.
- **Мест не хватает:** кнопка «Принять» не показывается, вместо неё «Не хватает мест — откройте встречу на сайте, чтобы увеличить лимит».

## 7. Уведомления

- Бот раз в 30 секунд проверяет непрочитанные уведомления каждого подключённого человека (`GET /api/notifications?unread`). Новые присылает сообщением с кнопками по типу:

| Тип | Кнопки |
|---|---|
| новая заявка | [Разобрать] |
| вас приняли | [Как добраться] [Отменить запись] |
| освободилось место | [Подтвердить место] [Отказаться] |
| ответ в обсуждении, изменение встречи | [Открыть] |
| напоминание | [Как добраться] [Не смогу прийти] |

- Уведомление на сайте прочитанным не отмечается: человек увидит его и там. Бот запоминает, что уже отправил.
- `/settings`:
  - «все»;
  - «только важные» — заявки, решения, изменения, отмены, места;
  - «выключить»;
  - тихие часы, по умолчанию 22:00–08:00 по городу: ночью ничего не приходит, утром одна сводка.

## 8. Помощник (свободный текст)

- Любой текст уходит в `POST /api/assistant/chat` с последними 12 сообщениями этого чата (бот хранит их у себя) и городом. Ответ превращается так:
  - текст — в сообщение;
  - подобранные встречи — в карточки п. 4;
  - быстрые ответы — в кнопки;
  - действие помощника («записать на первую», «добавить в избранное», «создать встречу») — в подтверждение [Подтвердить] [Отмена], как на сайте. Выполняет действие бот своим запросом.
- Если помощник недоступен, бот отвечает правилами: поиск по фразе через `/api/assistant/search` + `/match`, справка по ключевым словам.
- Лимит помощника на сайте — 12 запросов в минуту на человека или IP. Бот ходит с одного адреса, поэтому сайт считает лимит по человеку в боте (заголовок `X-Bot-Chat`, его принимают только от запроса с секретом бота).

## 9. Запуск

### Telegram — на домашнем ПК
1. В @BotFather: `/newbot`, имя «Спорт и точка», ник, например `sport_i_tochka_bot`. Скопировать ключ.
2. `scripts/set-telegram-bot.ps1`. Скрипт:
   - спрашивает ключ бота скрытым вводом и сохраняет его зашифрованным в профиле Windows;
   - берёт секрет привязки с сервера по SSH.
3. `scripts/run-telegram-bot.ps1` — запуск. Окно можно свернуть. Для автозапуска есть `-Install`: задача в Планировщике при входе в Windows.
- Состояние (подключённые люди, история, отправленные уведомления) лежит в `%LOCALAPPDATA%\sport-i-tochka\telegram-bot.sqlite`. Ключи людей в базе зашифрованы (DPAPI).
- Пока ПК выключен, бот молчит. Сообщения Telegram хранит до 24 часов и отдаст их при запуске. Уведомления за это время придут сводкой.

### VK — на сервере
1. В сообществе: «Управление → Сообщения» — включить; «Сообщения → Настройки для бота» — включить возможности ботов и кнопку «Начать».
2. «Работа с API → Ключи доступа» — ключ с правами «сообщения сообщества», «фотографии», «управление сообществом». «Long Poll API» — включить, версия 5.199, события `message_new`, `message_event`, `message_allow`.
3. `scripts/set-vk-bot-token.ps1` — ключ вводится скрытно и уходит прямо в `deploy/.env` на сервере по SSH.
4. Сервис `vk-bot` в `docker-compose` стартует вместе с сайтом и ходит в бэкенд внутри сети.

## 10. Безопасность
- В чат не вводятся пароль и почта. Сайт выдаёт ключ только по одноразовому коду (10 минут, одно использование).
- Запросы привязки подписаны общим секретом бота (`BOT_API_SECRET`). Без него `/api/bots/link` не работает.
- Ключ бота можно отключить на сайте одной кнопкой.
- Бот не пересылает чужие персональные данные. Организатор видит заявителя так же, как на сайте.
- Защита от злоупотреблений:
  - не больше 30 сообщений в минуту от одного человека;
  - тяжёлые запросы в очереди;
  - бот не пишет первым тем, кто его не запускал: VK требует `message_allow`, Telegram сам блокирует такие сообщения.

## 11. Проверка
- `bots/tests`: сценарии ядра на подменённом сайте и мессенджере — привязка, поиск, запись со всеми ветками, создание встречи с фото, заявки, уведомления, тихие часы, ошибки сайта.
- Сервер (pytest): ссылка-привязка, обмен кода на ключ, ключ работает везде, отзыв, чужой секрет, просроченный и повторный код.
- Вживую: бот против локального сайта в Docker, затем против sport.up-point.tech.
