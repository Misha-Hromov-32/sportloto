# Оценка помощника на правилах

Набор из 65 фраз с эталонными ответами лежит в `backend/tests/assistant_eval_cases.json`, рядом с тестом,
потому что контейнер с тестами видит только папку `backend/`. В наборе: поиск фразой, черновики события,
«Ищу компанию» и заявки организации, предмодерация и диалог подбора на демо-данных. «Сегодня» —
понедельник 19 октября 2026, 12:00 по Красноярску.

Тест `backend/tests/test_assistant_eval.py` прогоняет фразы через помощника и считает, сколько кейсов
каждого вида верны целиком. Если число стало меньше порога (`PASS_AT_LEAST` в тесте), тест падает. Сейчас
порог — все 65 кейсов.

Запуск вместе с остальными тестами бэкенда:

```sh
docker compose -f deploy/docker-compose.yml run --rm backend-test
```

Только оценка, с таблицей и промахами в выводе:

```sh
docker compose -f deploy/docker-compose.yml run --rm backend-test pytest -q -s tests/test_assistant_eval.py
```

Как считается: название, место и «что взять» сравниваются по основам слов. Кейс засчитывается, если
найдено не меньше половины значимых слов эталона, а для места — не меньше 60%. Описание и текст
объявления не проверяются, потому что переносятся из фразы как есть. Уровень `advanced` в наборе
соответствует нашему `experienced`.

Правила подбирали на этом же наборе, поэтому 100% — оценка сверху. Новые фразы лучше добавлять в набор
отдельно от правок правил.
